# Каталог FiVi

Загрузи содержимое этой папки в корень публичного GitHub-репозитория `fivi-catalog` (ветка `main`). В настройках FiVi укажи GitHub username владельца репозитория. Приложение получает `catalog.json` и файлы из `posters/` и `logos/` напрямую из GitHub Raw.

## Добавить сериал

Добавь объект в массив `shows` файла `catalog.json`. У каждого объекта обязательны `id`, `title`, `studio`, `description`, `tags`, `color`, `poster`, `videos`, `episodes`. Постер/логотип положи в соответствующую папку и укажи относительный путь. Видео добавляй только по официально доступным URL/YouTube ID и с разрешением правообладателя.

## Разделы главного экрана

Объект `sections` сопоставляет заголовки массивам `id` сериалов. Например:

```json
"sections": {
  "Новинки": ["villainous"],
  "Популярные": ["murder-drones", "digital-circus"]
}
```

После commit изменений каталог обновится в FiVi автоматически при следующем запуске или вручную через Настройки → Онлайн-каталог.
